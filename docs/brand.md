# Brand

A stone beacon on a dark hillside. The interface is calm, dark and quiet; colour appears only when
something actually burns.

## Assets (`assets/brand/`)

The mark is the beacon seal: a cairn of three angular stones on a hilltop with a fire on top,
framed by a horizon ring. In the primary ("breakout") form the ring opens at the top and the fire
rises through it: everything stays inside the frame except the warning.

| File | Use |
|---|---|
| `mark.svg` | Primary mark (breakout, lit), 32 px and up |
| `mark-unlit.svg` | Closed ring, cold beacon: "all clear" state in the UI status hero |
| `mark-mono.svg` | Single colour (`currentColor`) breakout mark |
| `mark-open.svg` | No ring, enlarged cairn and fire: below 32 px |
| `favicon.svg` | Open mark in mid-grey, readable on light and dark tabs (no inline styles, CSP-safe) |
| `badge.svg` | Filled night disc: avatars, app icon, Docker Hub |
| `wordmark.svg` | Lowercase monoline "varde" in `currentColor`, outlined paths (no font dependency) |
| `lockup-dark.svg`, `lockup-light.svg` | Mark + wordmark for dark and light backgrounds |
| `social-preview.svg/.png` | GitHub social preview, 1280x640 |
| `avatar.svg/.png` | Organisation avatar, 500x500 |
| `mark-512.png`, `badge-512.png`, `favicon-32.png`, `apple-touch-icon.png` | Raster exports |

PNG files are generated by `scripts/render-brand.sh` (rsvg-convert, Inter for the tagline) and
committed.

Construction (64-unit grid): ring r = 29.5, stroke 3, opened ±22° at the top. Hill: a circle
segment of r = 25.5 under a quadratic crest at y ≈ 42. Three stones as irregular quadrilaterals,
offset alternately so they read as a stacked cairn rather than stripes. Flame centred at x = 33.2
with a lighter core. Wordmark: monoline, round caps, stroke 3.8, even letter gaps; in the lockup
its x-height is centred on the ring's centre.

Size rule: full seal from 32 px up, open mark below. The ring never appears below 32 px.

States: the UI hero uses `mark-unlit.svg` while nothing is urgent and `mark.svg` while a P1 finding
exists. The opening of the ring is part of the signal.

## Colour

UI tokens are CSS custom properties in `internal/web/static/css/varde.css`; a test verifies their
contrast. Brand reference values:

| Role | Dark theme | Light theme |
|---|---|---|
| Background | `#0E1318` | `#F6F4F1` |
| Surface | `#151C23` | `#FFFFFF` |
| Primary text | `#E7ECF0` | `#1E242B` |
| Muted text | `#93A1AE` | `#5C6773` |
| Stone (logo) | `#A3B0BC` | `#4F5A66` |
| Ember (P1, flame only) | `#F2602F` | `#E2501F` |
| Ember core | `#FFB27A` | `#FFB27A` |

Ember is used for P1 findings and the flame, nothing else. If nothing is urgent, the UI shows no
ember. Secondary states (amber for P2, blue-grey for P3/info, quiet green for "all clear") are
defined with the UI tokens. Meaning is never carried by colour alone.

## Type

System font stack for UI, system monospace for versions, IDs and hashes. No web font downloads.
The wordmark is drawn as paths and does not depend on a font.

## Voice

Short, factual, no exclamation marks, no emojis. Notifications start with `[varde] P1`.

> No action needed. 23 workloads watched, last check 4 minutes ago.
