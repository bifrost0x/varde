{{else if eq $d.Kind "proxmox-lxc"}}

One key line on the Proxmox node lets Varde read the packages of every running LXC container, without signing in to each one. The key runs one fixed command as root on the node: it lists the containers and, for each running one, reads a few files with pct exec <id> -- cat inside the container, with the container's own rights. Nothing is installed or changed.

{{else if eq $d.Kind "packages"}}

Varde signs in over SSH with a key that can run one fixed, read-only command: it lists the installed packages (dpkg, rpm, apk) and the systemd services. Nothing is installed on the host and Varde keeps only packages and services of apps in its catalog.

{{else}}

Varde reads the containers through the Docker Engine API over SSH, the way docker -H ssh:// does. Nothing is installed on the host.

{{end}}

Step 3: Create a read-only token

In the shell of the node (node › Shell), run:

pveum user add varde@pve --comment "Varde (read-only)"
pveum acl modify / --users varde@pve --roles PVEAuditor
pveum user token add varde@pve varde --privsep 0

The last command shows the token secret once. PVEAuditor can only read. Addresses of VMs come from the QEMU guest agent; on Proxmox 8 they also need VM.Monitor, on Proxmox 9 VM.GuestAgent.Audit (part of PVEAuditor).
