Advisory data

Where the advisories come from, and how fresh they are.

{{if eq $d.Mode "package"}}

Data package: Varde reads one signed package the project builds once a day, the same for every installation. The package's mirror learns nothing about the apps you run{{if $d.Direct}}; for apps the package does not cover Varde asks api.github.com, as switched on under Settings{{end}}. The optional sources below, where switched on, are asked as before.

{{else if eq $d.Mode "feed"}}

Feed mode: Varde downloads the signed central feed, the same data for every installation. Upstream sources learn nothing about the apps you run.

{{else if eq $d.Mode "hybrid"}}

Hybrid mode: Varde uses the signed central feed. Where direct queries are switched on, it asks GitHub about local catalog entries and apps the feed does not cover; GitHub learns about those apps from the advisory repositories requested.

{{else}}

Direct mode: Varde queries upstream sources itself. GitHub learns which apps you run from the advisory repositories requested. A signed central feed, where every installation downloads the same data, is planned and will avoid this.

{{end}}
