Agents

Install the agent

Varde signs in to each host once over SSH, installs its agent as a service and forgets the credentials. From then on the agent reports the full inventory of the host by itself: every installed package and, if you allow it, every Docker container. It connects out to this server and needs no open port, and it updates itself to the version of this server.

Remove the agent from a host

Run as root: signed in as another user, put sudo in front (or use su -c). With systemd:

sudo sh -c 'systemctl disable --now varde-agent; rm -f /etc/systemd/system/varde-agent.service /etc/varde-agent.env; systemctl daemon-reload; rm -rf /var/lib/varde-agent; userdel varde-agent'

With OpenRC (Alpine):

sudo sh -c 'rc-service varde-agent stop; rc-update del varde-agent; rm -f /etc/init.d/varde-agent /etc/varde-agent.env; rm -rf /var/lib/varde-agent; deluser varde-agent'

Then revoke the agent under Connections › Agents.

What Varde does on each host

In one SSH session: read the platform ({{range $i, $p := $d.Platforms}}{{if $i}}, {{end}}{{$p}}{{end}} are available), upload the agent binary, its configuration with a one-time enrollment token and an install script into a private temporary directory, and run the script as root. The script creates the system user varde-agent without a login, installs the agent to /var/lib/varde-agent, its configuration to /etc/varde-agent.env and a hardened systemd or OpenRC service, starts it and removes the temporary directory. Running it again updates the installation. Varde stores neither the password nor the key.
