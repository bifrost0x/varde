varde

Set up Varde

Create the first account with the one-time setup token. Varde printed it to its log when it started; it works once and for 24 hours.

Where is the setup token?

Run one of these on the machine that runs Varde and copy the value after setup_token=, without the setup_token= itself:

Linux, macOS
docker logs {{.Data.Container}} 2>&1 | grep setup_token
Windows (cmd)
docker logs {{.Data.Container}} 2>&1 | findstr setup_token
Windows (PowerShell)
docker logs {{.Data.Container}} 2>&1 | Select-String setup_token
Docker Compose
docker compose logs varde | grep setup_token
Without Docker (systemd)
journalctl -u varde | grep setup_token

{{if eq .Data.Container ""}}Replace <varde-container> with the name of Varde's container (docker ps lists it). {{end}}No token in the log, or older than 24 hours? Restart Varde; it prints a new one while no account exists.
